# Stamp eraser texture sources

Downloaded on 2026-10-27 from ambientCG. Stored maps are 8-bit grayscale
PNG conversions of the official surface-preview Roughness maps (2048 px), reduced to 512 px using nearest-neighbor sampling, with contrast normalization.
They supply the pattern only; runtime transforms and thresholds produce binary
keep/erase masks. No runtime network access is needed.

- `metal007.png`: Metal007, official Roughness tiling-preview map
  https://f003.backblazeb2.com/file/ambientCG-Web/media/surface-preview/Metal007/Metal007_SQ_Roughness.jpg
  https://ambientcg.com/view?id=Metal007
