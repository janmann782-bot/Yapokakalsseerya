# InfoBox Bot 1.10.0

Telegram-бот для энциклопедических карточек о реальных и вымышленных объектах. В боте есть страны, регионы, битвы и персонажи, быстрый текстовый ввод, свои поля и разделы, изображения, три темы, PNG-экспорт и отправка всей карточки обычным текстом.

Project:Aurelia здесь только одна из тем оформления. Шаблоны и данные не завязаны на конкретную вселенную.

Проект намеренно плоский: все исходники лежат в одной директории. Папок `app`, `services`, `repositories` и прочей матрешки нет.


## Версия 1.10.0 - HOI4 Карточка (бета)

В "Еще форматы" пункт суперевентов заменен на "HOI4 Карточка (бета)".
Выбери TNO или TFR, затем государство, событие или "Все в 1 фотке".
В TNO есть отдельная газета; в общей картинке TNO она тоже присутствует.

Флаг, портрет, картинка события, фото газеты и значки загружаются отдельно.
Редактор показывает поля выбранного формата. Стиль и формат можно менять
в "Оформлении"; скрытые данные сохраняются. Доли партий вводятся строками:
`ЛПК | 40 | #ffcc00`. Числа обозначают относительные доли, нормируются на полный круг.
Без долей диаграмма остается неопределенной, никаких выдуманных процентов.

Шрифты и оригинальные элементы извлечены из PSD пользователя. PSD и Photoshop
на хостинге не нужны. Старые суперевенты открываются как события TFR.
Текст переносится и уменьшается в пределах читаемого размера; при переполнении
бот объясняет какое поле сократить, вместо молчаливого обрезания строк.

Пример через реальную базу и рендер бота:

```bash
python demo_hoi4.py --output-dir /absolute/path --source /path/to/existing_Ralizm_image.png
```

Факты примера взяты из государственного реестра Кефирстана на 2062 год.
"Власть по контракту" - заголовок демонстрации, не новое каноническое событие.
Подготовка графики описана в `assets/hoi4/README.md`.

## Версия 1.9.1 - парламент

Полукруг целиком вписывается в ширину PNG. Число рядов может расти, но места
больше не обрезаются по краям. Круги и квадраты масштабируются вместе с
расстояниями между ними.

Партии занимают сектора слева направо через все ряды: от нижнего левого края
к верхней части и затем к нижнему правому краю. Порядок партий соответствует
строкам ввода. Раньше цвета шли по целому внутреннему ряду, затем по следующему.
Пустые места остаются серыми. HTML/SVG и PNG используют общую геометрию.

Исправлен и случай с 1-3 местами. Старые сохраненные PNG парламента при первом
открытии или экспорте собираются заново. Данные партий не меняются.

Проверка:

```bash
python -m unittest test_core test_bot test_wikipedia test_navigation test_parliament_layout -q
```

Проверяются точное число мест, края изображения, зазоры между кругами и
квадратами, сектора партий, SVG и обновление старого PNG. Геометрия проверяется
для палат от 1 до 10 000 мест, а не только для примера на 240 депутатов.

## Версия 1.9.0 - интерфейс по Pismo v8 Vox

Тексты и кнопки переписаны по приложенному автором Pismo v8 Vox. Разговорная
подача без декоративных рамок и канцелярита. В текстах интерфейса прямые двойные
кавычки, обычный дефис и буква "е". Ввод пользователя остается без изменений.
Шрифт и оформление самих карточек сохранены.

Из меню можно собрать карточку, открыть свои карточки, продолжить черновик,
зайти в настройки и помощь. Старые команды и кнопки предыдущего меню работают.

После выбора типа доступны 3 способа:
- пройти по шагам и при желании сразу перейти в редактор;
- вставить готовый текст строками "Поле: значение";
- написать название и открыть редактор с разделами.

Редактор показывает заполненность каждого раздела. Правки записываются без
создания PNG после каждого поля. Для рендера нажмите "Посмотреть карточку".
Кнопки "Скачать PNG" и "Забрать текст" выполняют именно указанное действие.
Поиск карточек работает с русскими названиями без учета регистра. В списке
по 8 карточек с переходом между страницами.

Черновик сохраняется в SQLite после обработанных действий. Выход в меню и
перезапуск бота его не удаляют. "Продолжить черновик" открывает данные в
редакторе. Замена новым черновиком и удаление требуют отдельного нажатия.
После сохранения карточки черновик удаляется. База и медиафайлы должны
оставаться на постоянном диске сервера. Это 1 текущий черновик на пользователя.

Экран мастера обновляется на месте. Переход от изображения к текстовому меню
может создавать новое сообщение - Telegram различает эти типы сообщений.
Язык и формат без альтернатив больше не занимают кнопки в настройках.
Загрузка картинок файлами больше не перехватывается обработчиком шрифтов.
Исправлены возврат после поиска шрифта и переходы редактора сторон битвы.

Проверка и схема экранов без подключения к Telegram:

```bash
python -m unittest test_core test_bot test_wikipedia test_navigation -q
python demo_interface.py --output-dir ./demo_output
```

Тестовый транспорт записывает методы Telegram локально. Настоящие сообщения
не отправляются. Схема показывает реальные тексты и кнопки обработчиков;
цвета и размеры в Telegram определяет клиент пользователя.

## Установка

Нужен Python 3.11 или новее.

Linux/macOS:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
Copy-Item .env.example .env
```

Если Linux сообщает о недостающих системных библиотеках Chromium:

```bash
playwright install --with-deps chromium
```

Открой `.env` и замени пример токена на токен от `@BotFather`:

```env
BOT_TOKEN=1234567890:replace_me
INFOBOX_DB_PATH=./infobox.db
INFOBOX_WORK_DIR=.
MAX_IMAGE_MB=12
LOG_LEVEL=INFO
```

Секреты в коде не хранятся. Файл `.env` уже исключен из Git.

## Запуск

```bash
python main.py
```

Бот использует long polling. Сохраненные страницы остаются в SQLite после перезапуска. Незаконченные черновики хранятся в памяти и после перезапуска пропадают — для MVP это нормальное поведение.

### BotHost

- файл запуска: `main.py`;
- команда запуска: `python main.py`;
- переменная окружения: `BOT_TOKEN`;
- команда сборки: `pip install -r requirements.txt && playwright install chromium`.

В значение `BOT_TOKEN` вставляется только сам токен из `@BotFather`, без кавычек и без
приписки `BOT_TOKEN=`. Если в логах написано, что Telegram отклонил токен, старое
значение нужно удалить в панели BotHost, сохранить новое и полностью перезапустить бота.

## Быстрый ввод

Можно отправить боту:

```text
Тип: страна
Название — Республика Гринвальд
Столица Норд
Население: 18 миллионов
Площадь 420 000 км²
Форма правления: парламентская республика
Магическая мощность: 820 ед.
Описание: северное государство...
```

Неизвестная подписанная строка станет пользовательским полем. Сомнительные строки бот покажет отдельно перед предпросмотром.

Для региона можно прислать, например:

```text
Тип: регион
Название: Верхняя Бавария
Страна: Германия
Входит в: Бавария
Административный центр: Мюнхен
Площадь: 17 529 км²
Население: 4 238 195
```

Кнопка `📋 Выслать текстом` собирает все заполненные стандартные поля, свои поля, свои разделы и подписи к изображениям. Если текст длиннее лимита Telegram, бот сам разбивает его на несколько сообщений.

Пользовательский раздел отправляется одним сообщением:

```text
ВОЕННЫЕ ДАННЫЕ
Армия: 250 000
Резерв: 600 000
Танки: 1200
```

## Renderer

`renderer.py` сначала строит автономный HTML без внешних ссылок. Пользовательский текст экранируется, а проверенные изображения встраиваются как `data:` URI и собираются в галерею. Затем Playwright открывает HTML в headless Chromium и делает screenshot самого инфобокса с автоматической высотой.

Если хостинг не установил Chromium или временно не может его запустить, бот автоматически
переключается на запасной renderer через Pillow. Он тоже поддерживает кириллицу, изображения,
три темы, перенос строк, свои поля и секции. Поэтому отсутствие браузера больше не ломает PNG.

Для Светлой и Темной темы используются Liberation Sans для основного текста и Liberation Serif для крупных заголовков. Renderer ищет их в стандартной системной папке Liberation; Chromium также имеет запасной стек Arial/Georgia/sans-serif/serif. Aurelia использует Isaac Fill при наличии файла рядом с кодом. Подпись `INFOBOX BOT` можно включать и отключать в настройках;
после переключения сохраненные предпросмотры автоматически пересобираются.

Тема Aurelia использует приложенный `Isaac Fill`, акцент `#A9F38F`, черный внешний фон,
одну цельную внутреннюю обводку и рамки в три раза толще обычных тем. Цвет текста совпадает с акцентом. Строки таблицы внутри карточки чередуются: черная и очень темно-зеленая `#132A18`, чтобы поля читались как таблица, но тема не превращалась в сплошную зеленую заливку. Свечение, тени и
градиенты не используются. Для отсутствующих в Isaac символов, например `є`, подключается
встроенный кириллический fallback. Метаданные Isaac указывают лицензию
`FontStruct Non-Commercial License`; перед коммерческим использованием это нужно учитывать.

Цвета не разбросаны по renderer. Каждая тема — один объект `Theme` с фоном, панелями, текстом, рамками, шрифтами, радиусом и пиксельным акцентом. Добавление темы не требует нового набора `if`.

Шаблон устроен так же: `Template` содержит список `Field`, короткий набор полей мастера и название типа основного изображения. Подписи хранятся рядом с данными галереи и относятся к конкретным файлам. Renderer группирует поля по секциям и отдельно понимает двухколоночные секции битвы через свойство `column`, а не через проверку названия шаблона.

## Границы MVP

Сейчас нет web-интерфейса, публичных URL, совместных миров, поиска, PDF и пользовательских шаблонов. Текущая структура им не мешает: данные уже отделены от Telegram, HTML вынесен из экспорта PNG, а темы и шаблоны декларативные. Добавлять эти функции заранее в код не нужно.


### Редактор сторон битвы

У страниц типа «Битва» есть отдельная кнопка «⚔️ Редактор сторон». Каждая сторона имеет своё название и список до 10 участников. Для участника можно задать имя и отдельный флаг. Старые поля `side_1` и `side_2` остаются совместимыми и автоматически используются при первом открытии редактора. Флаги хранятся как обычные медиа страницы, поэтому подходят и для HTML, и для Pillow-рендера.

## Отдельные визуальные типы

В меню создания доступны самостоятельные типы карточек:

- `🏛 Парламент` — полукруг мест, легенда партий, порог большинства, флаг страны и логотипы партий. Партии вводятся строками `Название | места | #цвет`. Флаг загружается с подписью `pflag:`, логотип партии — `party: Название партии`.
- `📈 График` — линия, столбцы или круг. Данные: `X | значение | #цвет`.
- `📊 Сравнение` — горизонтальные полосы. Данные: `Название | значение | #цвет`.
- `🗳 Выборы` — составная полоса и результаты кандидатов/партий. Данные: `Название | результат | #цвет`.
- `🕒 Хронология` — события в формате `Дата | событие`.
- `👥 Состав` — доли групп и составная полоса. Данные: `Название | значение | #цвет`.

Эти типы не являются полями страны/региона: они сохраняются как отдельные страницы, как `Страна`, `Битва` или `Персонаж`.
